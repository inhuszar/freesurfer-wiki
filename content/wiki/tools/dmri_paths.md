# dmri_paths

## Summary

`dmri_paths` performs probabilistic global tractography using a Bayesian MCMC (Markov Chain Monte Carlo) framework. Given diffusion MRI data, anatomical priors (trained by `dmri_train`), and end-region-of-interest (ROI) masks, it samples from the posterior distribution over the spatial course of white-matter fiber pathways to produce a probabilistic path map for each white-matter tract of interest.

## Source Information

- **Language:** C++
- **Source files:** `trc/dmri_paths.cxx`, `trc/coffin.h`, `trc/coffin.cxx`
- **Binary:** `/usr/local/freesurfer/8.2.0/bin/dmri_paths`
- **Original author:** Anastasia Yendiki (MGH)
- **Core algorithm:** `Coffin` class in `coffin.cxx`

## Purpose and Context

`dmri_paths` is the tractography engine of the **TRACULA** (TRActs Constrained by UnderLying Anatomy) pipeline. Unlike streamline tractography that follows the local diffusion direction, TRACULA uses a global probabilistic approach where:

1. Spatial priors on tract shape and anatomy (from training data) constrain plausible path configurations.
2. Diffusion data provides a likelihood for the local fiber orientation at each path point.
3. MCMC sampling explores the posterior over path configurations.

This produces a spatial probability map (not a set of streamlines) indicating how likely each voxel is to be traversed by the tract.

## Mathematical Foundations

TRACULA uses a **Bayesian global tractography** model. The posterior over path $\mathcal{P}$:

$$
p(\mathcal{P} | \mathbf{Y}, \boldsymbol{\theta}_0) \propto p(\mathbf{Y} | \mathcal{P}) \cdot p(\mathcal{P} | \boldsymbol{\theta}_0)
$$

where $\mathbf{Y}$ is the diffusion MRI data and $\boldsymbol{\theta}_0$ are trained prior parameters.

**Likelihood** $p(\mathbf{Y} | \mathcal{P})$: Measured using fiber orientation distributions from BEDpostX. At each path point, the likelihood is high if the path direction aligns with the inferred fiber orientation.

**Prior** $p(\mathcal{P} | \boldsymbol{\theta}_0)$ encodes:
- **Spatial (xyz) prior:** Probability of path passing through each voxel, learned from training subjects
- **Tangent (direction) prior:** Probability of fiber orientation at each point
- **Curvature prior:** Penalizes sharp bends
- **Neighborhood anatomy prior:** Conditioned on local anatomical parcellation context
- **Local anatomy prior:** Voxel-level anatomical probability

The path is represented as a piecewise-linear curve parameterized by control points. MCMC (Metropolis-Hastings) sampling explores the space of control point configurations.

`dmri_paths` is the core computation step of the TRACULA pipeline:

```
recon-all (anatomy) --|
dmri_bset (preprocessing) --> BEDpostX --> dmri_paths --> dmri_pathstats --> dmri_group
dmri_train (priors) --------|
```

## Gotchas and Caveats

> [!gotcha] BEDpostX prerequisite
> `dmri_paths` requires BEDpostX output (fiber orientation distributions from FSL). This must be run separately before calling `dmri_paths`.

> [!gotcha] MCMC requires many iterations
> The default 5000 burn-in + 5000 sampling iterations make this computationally expensive. Runtime can be hours per tract per subject.

> [!gotcha] Prior files must match atlas space
> The prior files (`xyzPriorFile`, `tangPriorFile`, etc.) generated by `dmri_train` encode spatial information in a specific atlas space. The test subject must be registered to this space.
