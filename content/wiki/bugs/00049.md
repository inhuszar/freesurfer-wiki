# [severity-3] [bug-00049] `MRIvolTopoFix` — protect-original-voxels loop starts at `k=1`, dropping `crs[0]`

> [!bug] Synopsis
> `MRIvolTopoFix`
> ([`utils/mri2.cpp:5752-5876`](https://github.com/freesurfer/freesurfer/blob/v$FREESURFER_VERSION/utils/mri2.cpp#L5752-L5876))
> performs volume-based topology correction by dilation
> then erosion. To prevent the erosion phase from
> shrinking the original segmentation past the seed,
> the function records every "on" voxel of the input
> in `crs` and re-paints them after each erosion step:
>
> ```cpp
> for(int k=1; k < crs.size(); k++)                        // :5838
>   MRIsetVoxVal(mritmp,crs[k][0],crs[k][1],crs[k][2],0,onval);
> ```
>
> The loop starts at `k=1`, skipping `crs[0]` — the
> first on-voxel found during the bookkeeping pass
> ([`:5776-5791`](https://github.com/freesurfer/freesurfer/blob/v$FREESURFER_VERSION/utils/mri2.cpp#L5776-L5791)).
> If `MRIerodeNN` clips that voxel during a given
> erosion pass, the protect-step never restores it. Over
> repeated erosion iterations, the seed voxel can be
> permanently lost.

## Affected Artefacts

- **Tool:** [[mri_binarize]] with `--topo-fix`
  ([`mri_binarize.cpp:693`](https://github.com/freesurfer/freesurfer/blob/v$FREESURFER_VERSION/mri_binarize/mri_binarize.cpp#L693)
  is the only caller).
- **Pipeline stage:** none in default `recon-all`.
- **Triggering configuration:** `mri_binarize --topo-fix
  <bin> <out>` on any segmentation that requires erosion
  (i.e., where the dilated topology fix actually
  proceeds past `eno == 2`).
- **FreeSurfer version(s):** confirmed in
  `$FREESURFER_VERSION` (commit `d932c45b79`).

## Detailed Description

```cpp
std::vector<std::vector<int>> crs;
for(int c=0; c < binseg->width; c++){
  for(int r=0; r < binseg->height; r++){
    for(int s=0; s < binseg->depth; s++){
      double val = MRIgetVoxVal(binseg,c,r,s,0);
      if(val < 0.5) continue;
      std::vector<int> crs0;
      crs0.push_back(c); crs0.push_back(r); crs0.push_back(s);
      crs.push_back(crs0);                                 /* records every on-voxel */
      ...
    }
  }
}
...
while(1){                                                  /* erosion loop */
  ...
  MRI *mritmp = MRIerodeNN(binseg,NULL,NEAREST_NEIGHBOR_FACE,1);
  for(int k=1; k < crs.size(); k++)                        /* (!) starts at 1, not 0 */
    MRIsetVoxVal(mritmp,crs[k][0],crs[k][1],crs[k][2],0,onval);
  ...
}
```

The bookkeeping pass at `:5776-5791` populates `crs[0]`
with the first on-voxel scanned. The protect pass at
`:5838-5839` skips `crs[0]`, so `mritmp` retains the
erosion result at that single voxel rather than the
re-painted on-value.

Effect:
- one voxel may be lost per erosion pass — bounded by
  the volume of the seed,
- the lost voxel is the first scanned in raster order,
  i.e. has the lowest (c,r,s) lexicographic value among
  on-voxels — typically a corner of the seed,
- if that voxel is on a thin spur, losing it can change
  the topology / connectivity slightly.

## Root Cause

Standard off-by-one. The author likely thought `k=0`
was a header / sentinel slot. The vector is filled
densely from `k=0` upward, so the start should be `0`.

## Impact

- **Specific output:** a single voxel — the one with the
  lowest (c,r,s) raster order in the input — is omitted
  from the re-painted seed each iteration. Over `n`
  erosion iterations, the same voxel may be eroded `n`
  times.
- **Magnitude:** at most one voxel of the seed is
  permanently lost. For a typical topology-fix run on a
  smoothed binary mask, this is negligible — well below
  partial-volume effects in the input. For a
  small-volume seed (e.g., a thin tract or fissure
  segmentation) where every voxel matters, the loss
  could close a thin spur.
- **No effect** on default `recon-all` pipelines —
  `mri_binarize --topo-fix` is opt-in.

## Recommended Fix

```diff
--- a/utils/mri2.cpp
+++ b/utils/mri2.cpp
@@ -5836,7 +5836,7 @@ MRI *MRIvolTopoFix(MRI *binseg0, int onval, MRI *binseg, int ndilationsmax, int
     MRI *mritmp = MRIerodeNN(binseg,NULL,NEAREST_NEIGHBOR_FACE,1);
     // Protect the true seg voxels from erosion
-    for(int k=1; k < crs.size(); k++)
+    for(int k=0; k < crs.size(); k++)

```

## Workarounds

None needed for typical use; the loss is one voxel.
