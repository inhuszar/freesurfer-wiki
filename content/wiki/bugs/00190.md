# [severity-2] [bug-00190] make_average_volume — --keep-all-orig branch is dead because the volume loop never iterates over 'orig'; orig.all.mgz is never written

> [!bug] Synopsis
> `make_average_volume` advertises `--keep-all-orig` as "concatenate all
> orig vols into mri/orig.all.mgz". The concatenation is implemented
> inside the main volume-averaging loop, guarded by
> `if($KeepAllOrig && $volid == orig)`. But that loop only iterates over
> the volume IDs `nu` and `norm` — never `orig` — so the guard is never
> satisfied, the `mri_concat ... orig.all.mgz` call never runs, and
> `orig.all.mgz` is never produced. The `--keep-all-orig` flag is a
> silent no-op.

## Affected Artefacts

- **Tool(s):** [[make_average_volume]]
- **Pipeline stage(s):** _N/A_ — invoked by [[make_average_subject]] to
  build the volumetric part of an average subject (e.g. fsaverage-like
  templates). `--keep-all-orig` is an opt-in extra.
- **FreeSurfer version(s):** confirmed in `8.2.0` at commit `d932c45`.
- **Platforms:** all — purely shell control flow.
- **Triggering configuration:** `make_average_volume --keep-all-orig
  --subjects ...` (or with `--out`). The flag is accepted and sets
  `KeepAllOrig=1`, but has no effect: `mri/orig.all.mgz` is absent from
  the output.

## Detailed Description

The main loop that resamples and averages volumes is declared as

```tcsh
foreach volid (nu norm)
```

([`scripts/make_average_volume:103`](https://github.com/freesurfer/freesurfer/blob/v8.2.0/scripts/make_average_volume#L103)).
For each `$volid` it transforms every subject's `mri/$volid.mgz` to the
template, averages them into `mri/$volid.mgz`, and — only here — checks
whether to also concatenate the per-subject inputs into `orig.all.mgz`
([`scripts/make_average_volume:155-161`](https://github.com/freesurfer/freesurfer/blob/v8.2.0/scripts/make_average_volume#L155-L161)):

```tcsh
if($KeepAllOrig && $volid == orig) then
  echo "Concatenating all subjects' orig volumes"
  set cmd = (mri_concat $invollist --o $outdir/mri/orig.all.mgz)
  ...
endif
```

Because `$volid` only ever takes the values `nu` and `norm`, the
sub-condition `$volid == orig` is always false, so the body is
unreachable. The output `orig.mgz` that an average subject does contain
is created *after* the loop as a symlink to `nu.mgz`
([`scripts/make_average_volume:167`](https://github.com/freesurfer/freesurfer/blob/v8.2.0/scripts/make_average_volume#L167)),
confirming that `orig` is never a real loop volume here and that
`$invollist` at the time of the guard holds `nu` (then `norm`) inputs,
not `orig` inputs.

The flag is fully wired everywhere else: it is initialised
([`scripts/make_average_volume:32`](https://github.com/freesurfer/freesurfer/blob/v8.2.0/scripts/make_average_volume#L32)),
parsed
([`scripts/make_average_volume:521-527`](https://github.com/freesurfer/freesurfer/blob/v8.2.0/scripts/make_average_volume#L521-L527)),
and documented
([`scripts/make_average_volume:662`](https://github.com/freesurfer/freesurfer/blob/v8.2.0/scripts/make_average_volume#L662)) —
only the loop that would honour it omits `orig`.

### Expected Behaviour

With `--keep-all-orig`, the script should write
`$outdir/mri/orig.all.mgz` containing every subject's transformed `orig`
volume concatenated into a multi-frame file (per the help text).

### Observed Behaviour

`--keep-all-orig` sets `KeepAllOrig=1` but produces no `orig.all.mgz`.
The `"Concatenating all subjects' orig volumes"` message is never
printed. No error is raised; the flag silently does nothing.

### Reproducer

> [!gap] Reproducer not yet constructed
> Requires two or more recon'd subjects with `mri/orig.mgz` and
> `transforms/talairach.xfm`. The defect is evident from the loop bound:
>
> 1. `make_average_volume --keep-all-orig --out avgtest --subjects subjA subjB`
> 2. `ls $SUBJECTS_DIR/avgtest/mri/orig.all.mgz` → file does not exist.
> 3. The log shows the loop running for `nu` and `norm` only, and never
>    prints `"Concatenating all subjects' orig volumes"`.

## Code Reference (Unambiguous)

- **File:** `scripts/make_average_volume`
- **Function:** main volume-averaging loop (top-level script body)
- **Lines:** loop header `103`; dead guard `155-161`
- **Commit:** `d932c45`

```tcsh
foreach volid (nu norm)                                   # :103 — 'orig' is NOT in this list
  set invollist = ();
  foreach subject ($SUBJECTS)
    ...
    set invol = $SUBJECTS_DIR/$subject/mri/$volid.mgz
    ...
    set invollist = ($invollist $xfmvol);
  end

  set outvol = $outdir/mri/$volid.mgz
  set cmd = (mri_average $ConfFlag $invollist $outvol)
  ...

  # When keeping all orig, concat
  if($KeepAllOrig && $volid == orig) then                 # :155 — $volid is only ever nu/norm → never true
    echo "Concatenating all subjects' orig volumes"
    set cmd = (mri_concat $invollist --o $outdir/mri/orig.all.mgz)
    echo $cmd | tee -a $LF
    $cmd  | tee -a $LF
    if($status) exit 1;
  endif
end
```

## Root Cause

The concatenation guard tests `$volid == orig`, but `orig` was never
added to the loop's volume list `(nu norm)`. Either the loop list is
missing `orig`, or the guard is keyed on the wrong volume ID. Given the
help text ("concatenate all orig vols") and that `mri_concat` over
`$invollist` is meant to stack per-subject *orig* volumes, the intent is
for the loop to process `orig` so that, on the `orig` pass,
`$invollist` holds the transformed orig volumes to concatenate. As
written, the branch can never execute.

## Impact

- `--keep-all-orig` is an opt-in diagnostic/aux output, not part of the
  default average-subject build, and its absence does not affect the
  primary outputs (`nu`, `norm`, the `orig`/`T1`/`brain` symlinks, or the
  voted `aseg`). Hence severity 2.
- A user (or downstream script) that passes `--keep-all-orig` expecting
  `mri/orig.all.mgz` — e.g. to inspect inter-subject variability or to
  feed a per-subject stack into another tool — finds the file missing,
  with no warning. The failure is silent and easy to misattribute.

## Recommended Fix

Add `orig` to the loop's volume list so the existing guard can fire on
the `orig` pass:

```diff
-foreach volid (nu norm)
+foreach volid (nu norm orig)
```

With `orig` in the list, the `orig` iteration builds `$invollist` from
each subject's transformed `mri/orig.mgz`, averages it to
`mri/orig.mgz`, and (when `KeepAllOrig` is set) concatenates the same
inputs into `mri/orig.all.mgz`. This also makes the post-loop
`ln -s nu.mgz orig.mgz` at line 167 redundant for the averaged case; see
the alternative below if that symlink must be preserved.

### Alternative Fixes Considered

If `orig.mgz` must remain a symlink to `nu.mgz` (to avoid an extra
`mri_average` pass and keep current behaviour), do not add `orig` to the
loop; instead, lift the concatenation out of the per-`volid` loop into
its own block that builds an orig-input list explicitly:

```tcsh
if($KeepAllOrig) then
  set origlist = ()
  foreach subject ($SUBJECTS)
    # transform each subject's mri/orig.mgz to the template, append to $origlist
    ...
  end
  set cmd = (mri_concat $origlist --o $outdir/mri/orig.all.mgz)
  ...
endif
```

This is more code but decouples `orig.all.mgz` from the averaged-volume
list and keeps the `nu`/`norm`-only averaging untouched. The one-line
fix is simpler if averaging `orig` into `mri/orig.mgz` is acceptable.

> [!gap] orig vs nu for orig.mgz
> Choosing between the two fixes depends on whether the average
> subject's `mri/orig.mgz` should be a true average of subjects' `orig`
> volumes or remain a symlink to the averaged `nu`. The minimal fix
> changes that; the alternative does not. A maintainer should confirm
> the intended semantics of `orig.mgz` in the average subject.

## Workarounds (If Any)

Until patched, build the stack manually: transform each subject's
`mri/orig.mgz` to the template (the same `mri_convert --apply_transform`
the loop uses) and run `mri_concat` over the results to produce
`orig.all.mgz`. There is no flag combination that makes the built-in
branch fire.
