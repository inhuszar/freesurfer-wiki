# [severity-2] [bug-00060] `MRIframeMean` — weighted variant uses the wrong divisor

> [!bug] Synopsis
> `MRIframeMean`
> ([`utils/fmriutils.cpp:1683-1715`](https://github.com/freesurfer/freesurfer/blob/v$FREESURFER_VERSION/utils/fmriutils.cpp#L1683-L1715))
> computes the per-voxel mean across frames. The
> default API (with empty `FrameWeight`) computes
> `Σ_f vol[f] / nframes` — correct. The weighted API
> multiplies each `vol[f]` by `FrameWeight[f]` before
> accumulation but **still divides by `nframes`**:
>
> ```cpp
> for (f = 0; f < vol->nframes; f++) {
>   double val = MRIgetVoxVal(vol, c, r, s, f);
>   if (FrameWeight.size() != 0) val *= FrameWeight[f];
>   v += val;
> }
> MRIsetVoxVal(volmn, c, r, s, 0, v / vol->nframes);    /* :1710 */
> ```
>
> The correct divisor for a weighted mean is
> `Σ_f FrameWeight[f]`, not `nframes`. The function is
> "correct" only when the caller pre-normalises so that
> `Σ_f FrameWeight[f] == nframes` — which is not the
> obvious convention.

## Detailed Description

The header declaration
([`include/fmriutils.h:107`](https://github.com/freesurfer/freesurfer/blob/v$FREESURFER_VERSION/include/fmriutils.h#L107)):

```cpp
MRI *MRIframeMean(MRI *vol, MRI *volmn, std::vector<double> FrameWeight={});
```

A natural caller writes:

```cpp
std::vector<double> w(nframes, 0.5); // each frame weighted at 0.5
MRI *mn = MRIframeMean(vol, NULL, w);
```

For a flat-1 volume `vol` with `nframes = 4` and
`w = {0.5, 0.5, 0.5, 0.5}`:
- `Σ FrameWeight = 2.0`,
- `Σ vol[f] * w[f] = 2.0`,
- correct weighted mean: `2.0 / 2.0 = 1.0`,
- function returns: `2.0 / 4 = 0.5`.

Concretely: any uniform weight `α` gives a result of
`α × (true mean)`, off by the factor `α`. Non-uniform
weights produce more complex biases.

## Root Cause

The `FrameWeight` parameter was added (with default
`{}`) but the divisor was not updated to handle the
weighted case. The unweighted case (`FrameWeight ==
{}`) still divides by `nframes`, which is correct;
the weighted case re-uses that divisor.

## Impact

- **Currently latent.** No in-tree caller exercises
  the weighted branch.
- **External callers** passing non-empty
  `FrameWeight` get a result scaled by
  `Σ(FrameWeight) / nframes`. For uniform weights the
  scaling is constant; for non-uniform weights the
  result is *not* a weighted mean at all, but a
  weighted *sum* divided by `nframes`.

## Recommended Fix

```diff
--- a/utils/fmriutils.cpp
+++ b/utils/fmriutils.cpp
@@ -1697,6 +1697,12 @@ MRI *MRIframeMean(MRI *vol, MRI *volmn, std::vector<double> FrameWeight)
   if (volmn == NULL) {
     volmn = MRIallocSequence(vol->width, vol->height, vol->depth, MRI_FLOAT, 1);
     MRIcopyHeader(vol, volmn);
   }

+  /* Compute the divisor once: nframes for unweighted, sum-of-weights for weighted. */
+  double divisor = (double)vol->nframes;
+  if (FrameWeight.size() != 0) {
+    divisor = 0.0;
+    for (int f = 0; f < (int)FrameWeight.size(); f++) divisor += FrameWeight[f];
+  }
+
   for (c = 0; c < vol->width; c++) {
     for (r = 0; r < vol->height; r++) {
       for (s = 0; s < vol->depth; s++) {
        double v = 0;
         for (f = 0; f < vol->nframes; f++) {
           double val = MRIgetVoxVal(vol, c, r, s, f);
           if (FrameWeight.size() != 0) val *= FrameWeight[f];
           v += val;
         }
-        MRIsetVoxVal(volmn, c, r, s, 0, v / vol->nframes);
+        MRIsetVoxVal(volmn, c, r, s, 0, v / divisor);
       }
     }
   }
```

The divisor is computed once outside the voxel loop;
no per-voxel cost.

## Workarounds

External callers can pre-normalise their weights so
that `Σ_f FrameWeight[f] == nframes`, after which the
function returns a correct weighted mean.
