# [severity-1] [bug-00096] `MRIsetValuesOutsideRegion` only writes the eight corner blocks, not the actual outside

> [!bug] Synopsis
> `MRIsetValuesOutsideRegion`
> ([`utils/mri.cpp:15769-15787`](https://github.com/freesurfer/freesurfer/blob/v$FREESURFER_VERSION/utils/mri.cpp#L15769-L15787))
> claims to set every voxel **outside** the
> given region to `val`. The implementation:
>
> ```cpp
> for (x = 0; x < mri_dst->width; x++) {
>   if (x >= region->x && x < region->x + region->dx) continue;     /* skip if x in range */
>   for (y = 0; y < mri_dst->height; y++) {
>     if (y >= region->y && y < region->y + region->dy) continue;   /* skip if y in range */
>     for (z = 0; z < mri_dst->depth; z++) {
>       if (z >= region->z && z < region->z + region->dz) continue; /* skip if z in range */
>       MRIsetVoxVal(mri_dst, x, y, z, 0, val);
>     }
>   }
> }
> ```
>
> Because each axis-skip is a `continue` on the
> respective loop, the only voxels that reach
> the `MRIsetVoxVal` call are those for which
> **all three** axes are out of range. That's
> the set
>
>     {(x, y, z) : x out AND y out AND z out}
>
> — the eight corner blocks of the volume.
>
> The intended set "outside the region" is the
> negation of "inside the region":
>
>     NOT(x in AND y in AND z in)
>     = x out OR y out OR z out
>
> The function leaves untouched all voxels that
> are outside the region on one or two axes but
> inside on the remaining axis (i.e., the slabs
> directly beside the region). The output is
> wrong by the symmetric difference between the
> intended outside-set and the corners-only set.

## Detailed Description

### Worked example

Consider a 100×100×100 volume with
`region = (40, 40, 40, 20, 20, 20)` (a 20³ box
in the centre).

- "Outside the region" should set the entire
  volume except a 20³ box, i.e.
  `100³ − 20³ = 992 000` voxels.
- The implementation sets only voxels where
  **all three** of x, y, z are outside
  `[40, 60)`: that's
  `(40 + 40)³ = 80³ = 512 000` voxels — the
  eight corner blocks of the volume.
  
  Wait — let me recompute. Voxels with x in
  `[0, 40) ∪ [60, 100)` is 80 voxels per axis.
  The eight corner blocks are
  `40 × 40 × 40 × 8 = 512 000`. ✓
  
  Voxels actually intended ("outside region"):
  `100³ − 20³ = 992 000`. The implementation
  misses `992 000 − 512 000 = 480 000` voxels
  — slabs adjacent to the region on one or
  two axes.

### Correct implementation

The set "outside the region" can be written
several ways:

1. **De Morgan**:
   `if (!(x in xrange && y in yrange && z in zrange)) set;`
2. **Or-of-or**:
   `if (x out || y out || z out) set;`
3. Iterate the inside-region first to build a
   skip-mask, then write the rest.

The current chained-`continue` pattern would
be correct only if every axis predicate were
checked **inside** the innermost loop — but
even then, only the negation of the AND.

## Root Cause

The author wrote each axis check as an
early-`continue` in its own loop and read the
combined effect as "any axis outside → set,"
but a `continue` on the **outer** loop skips
the entire (y, z) plane, not just the current
voxel. The compound effect is the **AND** of
all three predicates, not the **OR**.

## Impact

- **In-tree:** none. The function is dead.
- **Severity:** 1 — dead code.

## Recommended Fix

```diff
--- a/utils/mri.cpp
+++ b/utils/mri.cpp
@@ -15769,16 +15769,16 @@ MRI *MRIsetValuesOutsideRegion(MRI *mri_src, MRI_REGION *region, MRI *mri_dst, f
 {
   int x, y, z;
 
   mri_dst = MRIcopy(mri_src, mri_dst);
 
   for (x = 0; x < mri_dst->width; x++) {
-    if (x >= region->x && x < region->x + region->dx) continue;
     for (y = 0; y < mri_dst->height; y++) {
-      if (y >= region->y && y < region->y + region->dy) continue;
       for (z = 0; z < mri_dst->depth; z++) {
-        if (z >= region->z && z < region->z + region->dz) continue;
+        bool inside = (x >= region->x && x < region->x + region->dx &&
+                       y >= region->y && y < region->y + region->dy &&
+                       z >= region->z && z < region->z + region->dz);
+        if (inside) continue;
         MRIsetVoxVal(mri_dst, x, y, z, 0, val);
       }
     }
   }
```

This computes the correct "outside the
region" set as the complement of the inside
test. The new check is performed inside the
innermost loop, so a single failed axis no
longer prematurely skips a whole slab.

## Workarounds

Don't use this function until the patch
lands; iterate the volume manually, or
allocate an inside-region mask and use
`MRImask`.
