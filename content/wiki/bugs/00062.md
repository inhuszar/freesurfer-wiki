# [severity-2] [bug-00062] `MRISrealloc{Vertices,Faces}` — classic realloc-into-itself anti-pattern

> [!bug] Synopsis
> `MRISreallocVertices`
> ([`utils/mrisurf_base.cpp:514-556`](https://github.com/freesurfer/freesurfer/blob/v$FREESURFER_VERSION/utils/mrisurf_base.cpp#L514-L556))
> and `MRISreallocFaces`
> ([`:578-606`](https://github.com/freesurfer/freesurfer/blob/v$FREESURFER_VERSION/utils/mrisurf_base.cpp#L578-L606))
> grow surface buffers using `realloc`. The pattern is:
>
> ```cpp
> mris->vertices = (VERTEX *)realloc(mris->vertices, max_vertices*sizeof(VERTEX));
> if (!mris->vertices) return false;
> #ifdef SEPARATE_VERTEX_TOPOLOGY
>   mris->vertices_topology = (VERTEX_TOPOLOGY *)realloc(mris->vertices_topology, ...);
> #endif
> mris->dist_storage      = (void**)realloc(mris->dist_storage,      ...);
> mris->dist_orig_storage = (void**)realloc(mris->dist_orig_storage, ...);
> ```
>
> When `realloc` fails, it returns `NULL` and *does
> not* free the original allocation. The
> `mris->vertices = realloc(mris->vertices, …)`
> assignment then **overwrites the only pointer to the
> original buffer** with `NULL`, leaking it. The
> caller's check `if (!mris->vertices) return false;`
> handles the first allocation but stops there.
>
> Worse: lines 530, 533, 534 (`vertices_topology`,
> `dist_storage`, `dist_orig_storage`) and lines
> 583, 587, 591 (`faces`, `faceNormCacheEntries`,
> `faceNormDeferredEntries`) **do not check the return
> at all**. If any of those reallocs fails, the field
> becomes NULL while subsequent `bzero` / `memcpy` on
> the now-NULL field segfaults.
>
> `MRISreallocFaces` instead uses `cheapAssert(...)`
> after each realloc, which on failure aborts the
> process — at least it doesn't dereference NULL, but
> the original buffers are still leaked before the
> abort.

## Affected Artefacts

- **Tools:** any code path that grows surface buffers
  via `MRISreallocVertices` or `MRISreallocFaces`.
  Internal callers include `MRISunion`,
  `MRISdivideEdges`, `MRISaddVertices` (etc.) —
  surface-construction primitives shared by many
  tools.
- **Pipeline stage(s):** none directly in default
  `recon-all`, since recon-all surface stages do not
  typically grow vertex / face counts mid-run beyond
  the initial allocation.
- **Triggering configuration:** out-of-memory at the
  exact moment of a vertex/face buffer grow.
  Practically rare on workstations with abundant RAM;
  more relevant in batch / cluster environments with
  per-process RSS limits.
- **FreeSurfer version(s):** confirmed in
  `$FREESURFER_VERSION` (commit `d932c45b79`).

## Detailed Description

`MRISreallocVertices`
([`utils/mrisurf_base.cpp:514-556`](https://github.com/freesurfer/freesurfer/blob/v$FREESURFER_VERSION/utils/mrisurf_base.cpp#L514-L556)):

```cpp
mris->vertices = (VERTEX *)realloc(mris->vertices, max_vertices*sizeof(VERTEX));
if (!mris->vertices) return false;                                       /* :526 — checked */
#ifndef SEPARATE_VERTEX_TOPOLOGY
  mris->vertices_topology = mris->vertices;
#else
  mris->vertices_topology = (VERTEX_TOPOLOGY *)realloc(...);             /* :530 — UNCHECKED */
#endif

mris->dist_storage      = (void**)realloc(mris->dist_storage,      ...); /* :533 — UNCHECKED */
mris->dist_orig_storage = (void**)realloc(mris->dist_orig_storage, ...); /* :534 — UNCHECKED */

int change = max_vertices - mris->nvertices;
if (change > 0) {
    bzero(mris->vertices          + mris->nvertices, change*sizeof(VERTEX));
#ifdef SEPARATE_VERTEX_TOPOLOGY
    bzero(mris->vertices_topology + mris->nvertices, change*sizeof(VERTEX_TOPOLOGY)); /* segfault if :530 returned NULL */
#endif
}

change = max_vertices - mris->max_vertices;
if (change > 0) {
    bzero(mris->dist_storage      + mris->max_vertices, ...); /* segfault if :533 returned NULL */
    bzero(mris->dist_orig_storage + mris->max_vertices, ...); /* segfault if :534 returned NULL */
}
```

`MRISreallocFaces`
([`:578-606`](https://github.com/freesurfer/freesurfer/blob/v$FREESURFER_VERSION/utils/mrisurf_base.cpp#L578-L606))
uses `cheapAssert(mris->faces);` after each realloc.
`cheapAssert` aborts on failure rather than
dereferencing NULL, so the segfault is replaced by an
abort — but the original buffers are still leaked
between the realloc returning NULL and the assert
firing.

In both functions, even a successful first realloc
followed by a failed second realloc leaks the second
buffer's original allocation: the `vertices` /
`faces` buffer is now the new (larger) allocation,
but `vertices_topology` / `faceNormCacheEntries` is
NULL, with the original allocation orphaned.

## Root Cause

The realloc-into-itself idiom is widely cited as an
anti-pattern. The correct form is:

```cpp
void *tmp = realloc(p, new_size);
if (!tmp) return false;
p = tmp;
```

This pattern was not applied here. The downstream
`bzero` calls assume the realloc succeeded, so a
failed realloc cascades into a NULL dereference.

## Impact

- **Under normal memory conditions:** unaffected.
  reallocs almost never fail on workstations.
- **Under OOM:** the function returns `false`
  (vertices case) or aborts (faces case), but in both
  cases the surface struct is in an inconsistent
  state and the originally-allocated buffers are
  leaked. Caller has no way to recover gracefully.
- **Severity:** low. Only manifests under OOM,
  which is rare in single-process runs but can occur
  in heavily-multiplexed cluster environments with
  per-process RSS caps.

## Recommended Fix

```diff
--- a/utils/mrisurf_base.cpp
+++ b/utils/mrisurf_base.cpp
@@ -522,12 +522,17 @@ bool MRISreallocVertices(MRIS * mris, int max_vertices, int nvertices) {

   cheapAssert(!mris->nverticesFrozen);

-  mris->vertices = (VERTEX *)realloc(mris->vertices, max_vertices*sizeof(VERTEX));
-  if (!mris->vertices) return false;
+  VERTEX *new_vertices = (VERTEX *)realloc(mris->vertices, max_vertices*sizeof(VERTEX));
+  if (!new_vertices) return false;
+  mris->vertices = new_vertices;
   #ifndef SEPARATE_VERTEX_TOPOLOGY
     mris->vertices_topology = mris->vertices;
   #else
-    mris->vertices_topology = (VERTEX_TOPOLOGY *)realloc(mris->vertices_topology, max_vertices*sizeof(VERTEX_TOPOLOGY));
+    VERTEX_TOPOLOGY *new_top = (VERTEX_TOPOLOGY *)realloc(mris->vertices_topology, max_vertices*sizeof(VERTEX_TOPOLOGY));
+    if (!new_top) return false;
+    mris->vertices_topology = new_top;
   #endif
-  mris->dist_storage      = (void**)realloc(mris->dist_storage,      max_vertices*sizeof(void*));
-  mris->dist_orig_storage = (void**)realloc(mris->dist_orig_storage, max_vertices*sizeof(void*));
+  void **new_ds  = (void**)realloc(mris->dist_storage,      max_vertices*sizeof(void*));
+  if (!new_ds) return false;
+  mris->dist_storage = new_ds;
+  void **new_dos = (void**)realloc(mris->dist_orig_storage, max_vertices*sizeof(void*));
+  if (!new_dos) return false;
+  mris->dist_orig_storage = new_dos;
```

Apply the same template to `MRISreallocFaces`.

A more thorough fix would also free the
already-grown buffers on partial failure (so that
returning `false` leaves `mris` in its pre-call
state). That requires saving the old pointers — more
invasive but safer.

## Workarounds

Run with adequate memory; the bug only manifests
under OOM.
