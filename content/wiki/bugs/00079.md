# [severity-1] [bug-00079] `utils/region.cpp` — three broken region-algebra primitives (all latent)

> [!bug] Synopsis
> Three of the region-algebra functions declared in
> [`include/region.h`](https://github.com/freesurfer/freesurfer/blob/v$FREESURFER_VERSION/include/region.h)
> are non-functional in
> [`utils/region.cpp`](https://github.com/freesurfer/freesurfer/blob/v$FREESURFER_VERSION/utils/region.cpp):
>
> - **`REGIONadd`**
>   ([`:108`](https://github.com/freesurfer/freesurfer/blob/v$FREESURFER_VERSION/utils/region.cpp#L108)):
>   `{ return (rdst); }` — empty stub. `rdst` is
>   returned uninitialised.
> - **`REGIONunion`**
>   ([`:165`](https://github.com/freesurfer/freesurfer/blob/v$FREESURFER_VERSION/utils/region.cpp#L165)):
>   `{ return (rdst); }` — empty stub.
> - **`REGIONsubtract`**
>   ([`:71-100`](https://github.com/freesurfer/freesurfer/blob/v$FREESURFER_VERSION/utils/region.cpp#L71-L100)):
>   computes only one of the four
>   reg2-overlaps-reg1 corner cases (truncate-from-
>   below) and has an off-by-one inside that case:
>   `rdst->x = MAX(x1_start, x2_end)` should be
>   `MAX(x1_start, x2_end + 1)` because `x2_end` is
>   the inclusive last index of `reg2` and the
>   subtracted region must start *after* it.
>
> All three are latent — `grep` over the v$FREESURFER_VERSION
> tree finds no callers outside the header
> declaration.

## Affected Artefacts

- **Tool:** none — the three functions have no
  in-tree callers.
- **Pipeline stage(s):** none.
- **Triggering configuration:** any external code
  linking against `libutils` that calls these
  functions directly.
- **FreeSurfer version(s):** confirmed in
  `$FREESURFER_VERSION` (commit `d932c45b79`).

## Detailed Description

### `REGIONadd` and `REGIONunion`

```cpp
/* utils/region.cpp:108 */
MRI_REGION *REGIONadd(MRI_REGION *reg1, MRI_REGION *reg2, MRI_REGION *rdst)
{ return (rdst); }

/* utils/region.cpp:165 */
MRI_REGION *REGIONunion(MRI_REGION *reg1, MRI_REGION *reg2, MRI_REGION *rdst)
{ return (rdst); }
```

Both functions accept the two operand regions and a
destination, then return the destination unmodified.
A caller would observe whatever `rdst` happened to
contain on entry (often uninitialised stack memory).

The companion `REGIONintersect`
([`:142-157`](https://github.com/freesurfer/freesurfer/blob/v$FREESURFER_VERSION/utils/region.cpp#L142-L157))
is fully implemented, so the empty stubs were
clearly unfinished placeholders rather than
deliberate no-ops.

### `REGIONsubtract`

```cpp
/* utils/region.cpp:71-100 */
MRI_REGION *REGIONsubtract(MRI_REGION *reg1, MRI_REGION *reg2, MRI_REGION *rdst)
{
  int x1_start, x1_end, x2_end, ... ;
  x1_start = reg1->x;
  x1_end   = reg1->x + reg1->dx - 1;
  x2_end   = reg2->x + reg2->dx - 1;

  rdst->x  = MAX(x1_start, x2_end);          /* :79 — off-by-one */
  rdst->dx = x1_end - rdst->x + 1;
  if (rdst->dx < 0) rdst->dx = 0;
  /* same for y, z */
}
```

Two issues:

1. **Off-by-one.** `x2_end` is the *inclusive* last
   index of `reg2`. To subtract `reg2` from `reg1`
   along the truncate-from-below axis, the result
   must start at `x2_end + 1` (the first voxel
   beyond `reg2`). As written, the result still
   contains `reg2`'s last voxel.
2. **Incomplete semantics.** A cuboid
   subtraction has four cases per axis (no
   overlap, reg2 truncates reg1 from below, reg2
   truncates reg1 from above, reg2 entirely inside
   reg1 — this last case cannot be expressed as a
   single cuboid). The implementation handles only
   the truncate-from-below case and silently
   garbles the others. The doc-comment at
   [`:64-69`](https://github.com/freesurfer/freesurfer/blob/v$FREESURFER_VERSION/utils/region.cpp#L64-L69)
   acknowledges the cuboid descriptor isn't rich
   enough for a general subtract, but the
   implementation doesn't even handle the cases it
   purports to cover.

## Root Cause

Unfinished implementation. The author scaffolded
the API in `region.h`, implemented `REGIONintersect`
and a partial `REGIONsubtract`, and left `REGIONadd`
and `REGIONunion` as `return rdst` placeholders. No
caller ever forced the issue.

## Impact

- **In-tree:** none. No FreeSurfer code calls any
  of the three functions.
- **External linkers:** any out-of-tree code
  linking `libutils` and using these symbols would
  silently get wrong results.
- **Severity:** low (latent dead API).

## Recommended Fix

Either delete the three functions from `region.cpp`
and `region.h` (preferred — they have no callers
and the `REGIONsubtract` semantics aren't
expressible as a cuboid in general), or implement
them correctly:

```diff
--- a/utils/region.cpp
+++ b/utils/region.cpp
@@ -76,7 +76,7 @@ MRI_REGION *REGIONsubtract(MRI_REGION *reg1, MRI_REGION *reg2, MRI_REGION *rdst)
   x1_end   = reg1->x + reg1->dx - 1;
   x2_end   = reg2->x + reg2->dx - 1;
-  rdst->x  = MAX(x1_start, x2_end);
+  rdst->x  = MAX(x1_start, x2_end + 1);
   rdst->dx = x1_end - rdst->x + 1;
```

(plus the parallel two-character fix on the y and
z axes). The empty-stub functions need a real
implementation modelled on `REGIONintersect`.

## Workarounds

Don't call these functions. Use `REGIONintersect`
or open-code the cuboid arithmetic at the call
site.
