# [severity-2] [bug-00097] `MRIscaleMeanIntensities` mutates `mri_src` instead of `mri_dst`

> [!bug] Synopsis
> `MRIscaleMeanIntensities`
> ([`utils/mri.cpp:13079-13122`](https://github.com/freesurfer/freesurfer/blob/v$FREESURFER_VERSION/utils/mri.cpp#L13079-L13122))
> rescales a source volume so that its mean
> intensity matches a reference volume's mean.
> The function:
>
> 1. Copies `mri_src` into `mri_dst` (allocating
>    `mri_dst` if NULL):
>
>    ```cpp
>    mri_dst = MRIcopy(mri_src, mri_dst);              /* :13084 */
>    ```
>
> 2. Computes per-volume means above intensity 10
>    (UCHAR brightness threshold) and a scale
>    factor `scale = ref_mean / src_mean`.
>
> 3. Loops the volume to apply the scale —
>    **writes to `mri_src`**, not `mri_dst`:
>
>    ```cpp
>    for (z = 0; z < depth; z++) {
>      for (y = 0; y < height; y++) {
>        for (x = 0; x < width; x++) {
>          val = MRIvox(mri_src, x, y, z);
>          val = nint(val * scale);
>          if (val > 255) val = 255;
>          MRIvox(mri_src, x, y, z) = val;             /* :13116 — wrong target */
>        }
>      }
>    }
>    return (mri_dst);
>    ```
>
> For a non-in-place call (`mri_dst != mri_src`)
> the result is:
>
> - `mri_src`: silently rescaled (input mutated).
> - `mri_dst`: still contains the original
>   unscaled `mri_src` values copied at `:13084`.
>
> The function's name and signature suggest a
> functional, non-mutating contract; the
> implementation is in-place against the wrong
> argument.

## Detailed Description

```cpp
/* utils/mri.cpp:13079-13122 */
MRI *MRIscaleMeanIntensities(MRI *mri_src, MRI *mri_ref, MRI *mri_dst)
{
  int width, height, depth, x, y, z, val;
  double ref_mean, src_mean, nref_vox, nsrc_vox, scale;

  mri_dst = MRIcopy(mri_src, mri_dst);                     /* :13084 — copy src→dst */
  ...
  /* compute ref_mean from mri_ref, src_mean from mri_src */
  scale = ref_mean / src_mean;

  for (z = 0; z < depth; z++) {
    for (y = 0; y < height; y++) {
      for (x = 0; x < width; x++) {
        val = MRIvox(mri_src, x, y, z);                    /* read mri_src */
        val = nint(val * scale);
        if (val > 255) val = 255;
        MRIvox(mri_src, x, y, z) = val;                    /* :13116 — WRITE mri_src */
      }
    }
  }
  return (mri_dst);                                        /* mri_dst is the un-modified copy */
}
```

For the in-place case (`mri_dst == mri_src`),
the `MRIcopy` at `:13084` is a no-op and the
write to `mri_src` is the write to `mri_dst`.
For the non-in-place case the writes go to the
wrong volume.

The straightforward fix is to either:

1. Read+write `mri_dst` consistently, leaving
   `mri_src` unchanged.
2. Or remove the `MRIcopy` (since it's
   redundant for in-place use) and document the
   function as in-place only.

## Root Cause

The function was likely originally an in-place
`MRI *MRIscaleMeanIntensities(MRI *mri,
MRI *mri_ref)` operating on the single input.
A `mri_dst` argument and a `MRIcopy` prefix
were later added to give it a functional
contract, but the body's `MRIvox(mri_src, ...)`
references were never updated to
`MRIvox(mri_dst, ...)`. The in-tree callers
all kept the old in-place form (`mri_dst ==
mri_src`), masking the mismatch.

## Impact

- **In-tree callers:** none affected — every
  call passes `mri_dst == mri_src`, so the
  in-place mutation gives the intended result.
- **Future callers** that pass a separate
  `mri_dst` (or `NULL` for fresh allocation)
  will get a returned `mri_dst` with the
  original unscaled values, while the
  caller's `mri_src` has been silently
  rescaled.
- **Severity:** 2 — latent under typical
  usage; conceptual mismatch between
  signature and implementation.

## Recommended Fix

```diff
--- a/utils/mri.cpp
+++ b/utils/mri.cpp
@@ -13110,11 +13110,11 @@ MRI *MRIscaleMeanIntensities(MRI *mri_src, MRI *mri_ref, MRI *mri_dst)
   for (z = 0; z < depth; z++) {
     for (y = 0; y < height; y++) {
       for (x = 0; x < width; x++) {
-        val = MRIvox(mri_src, x, y, z);
+        val = MRIvox(mri_dst, x, y, z);
         val = nint(val * scale);
         if (val > 255) val = 255;
-        MRIvox(mri_src, x, y, z) = val;
+        MRIvox(mri_dst, x, y, z) = val;
       }
     }
   }
```

This makes the function honour its `mri_dst`
output contract and leaves `mri_src`
unchanged. In-place callers continue to work
because the `MRIcopy` at `:13084` is a no-op
when `mri_dst == mri_src`.

## Workarounds

Always pass `mri_dst == mri_src` (in-place
form) until the patch lands.
