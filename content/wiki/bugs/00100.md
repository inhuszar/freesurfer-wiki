# [severity-3] [bug-00100] Five tissue-class mean/covariance estimators include one fake all-zero observation

> [!bug] Synopsis
> Five sibling functions in
> [`utils/mri.cpp`](https://github.com/freesurfer/freesurfer/blob/v$FREESURFER_VERSION/utils/mri.cpp)
> compute multimodal tissue-class means and
> covariances by collecting valid voxels into a
> matrix `m_data` and passing the populated
> region to `MatrixCovariance`. Each follows
> the pattern:
>
> ```cpp
> int a = 1;                                      /* row counter, 1-based */
> ...
> for (...) {
>   if (voxel_qualifies) {
>     for (n = 0; n < mri_inputs->nframes; n++)
>       m_data->rptr[a][n + 1] = MRIgetVoxVal(...);
>     a++;                                        /* post-increment after write */
>   }
> }
>
> m_data_final = MatrixCopyRegion(m_data, NULL, 1, 1, a, mri_inputs->nframes, 1, 1);
> MatrixCovariance(m_data_final, cov_final, means_final);
> ```
>
> After the loop, `a` is `1 + N` where `N` is
> the number of qualifying voxels. The valid
> data lives in rows `1..N = 1..a - 1`. The
> third argument to `MatrixCopyRegion` is the
> **number of rows** to copy; passing `a`
> copies rows `1..a` — including row `a`,
> which was never written and therefore
> contains the calloc-initialised zeros from
> `MatrixAlloc`.
>
> `MatrixCovariance` then computes the mean and
> covariance over `a` "observations," with one
> all-zero observation polluting every
> tissue-class statistic.

## Detailed Description

### Counter convention

`a = 1;` initialises the row counter to the
1-based row index where the next valid
observation will be written. Each qualifying
voxel performs the writes at row `a` for all
frames, then increments `a`. After the loop,
`a` points to the **next free row**, not the
last filled row.

The number of filled rows is therefore
`a − 1`. Passing `a` to `MatrixCopyRegion`
asks for one extra row — the next-free row —
which contains zeros from `MatrixAlloc`'s
`calloc`-style initialisation.

### Bias on means and covariance

For each modality `n`, the sample mean
becomes:

```
mean[n] = (sum_over_valid_voxels(val[n]) + 0) / a
       = (true_sum) / (N + 1)
       = (N / (N + 1)) * true_mean
```

So means are scaled down by `N/(N+1)`. For the
covariance:

```
cov[m,n] = (sum((x[m] - mean[m]) * (x[n] - mean[n])) + (0 - mean[m]) * (0 - mean[n])) / a
        = (sum_with_real_obs + mean[m]*mean[n]) / (N + 1)
```

Both bias terms are `O(1/N)` — small for large
N, but systematic. For tiny classes (e.g.,
hand-labelled WMSA voxels in a single
subject), N can be in the tens or hundreds
and the bias is ~0.5–1%.

### Five affected sites

```cpp
/* :16992 — MRIcomputeWMMeansandCovariances */

/* :17041 — MRIcomputeLabelMeansandCovariances */

/* :17087 — MRIcomputeWMSAMeansandCovariances */

/* :17135 — MRIcomputeCaudateMeansandCovariances */

```

All five were almost certainly copy-pasted
from the same template; the off-by-one was
duplicated five times.

## Root Cause

Off-by-one on a 1-based counter. The pattern
`a = 1; … rptr[a][...]; a++; …
MatrixCopyRegion(..., a, ...)` mixes "counter
points to next slot" (when reading after
post-increment) with "copy this many rows"
(when passed to `MatrixCopyRegion`). The
correct number to pass is `a − 1`.

## Impact

- **Tissue-class statistics:** all five
  estimators include one fake all-zero
  observation. Means biased down by
  `N/(N+1)`; covariance biased toward
  `mean[m] * mean[n]` (the "missed centring"
  contribution from the fake zero
  observation).
- **`mri_ca_label` (default recon-all):**
  WMSA reclassification thresholds are
  derived from these biased means/covariances.
  The bias is small but systematic and
  affects WM-hypointensity vs caudate vs
  ventricle decisions at boundary voxels.
  Compounds with bug [[00044]]
  (`GCAlabelWMandWMSAs` writing caudate
  covariance into the WM slot).
- **Severity:** 3 — flag-gated impact on
  tissue-class boundary decisions in default
  `recon-all`. Bias is bounded but
  observable on small classes.

`a > 0` to catch the empty-class case.

## Workarounds

None. The bias is small relative to the
class's natural variance for typical recon-all
inputs.

- **Discovered:** 2026-05-08 by agent

  collectors in `utils/mri.cpp`).
- **Evidence:**
  - Five sites use the identical pattern
    `a = 1; … rptr[a][...]; a++; …
    MatrixCopyRegion(..., a, ...)`.
  - `MatrixCopyRegion`'s third argument is
    `rows` (count, not end index) — see
    [`utils/matrix.cpp:1391-1407`](https://github.com/freesurfer/freesurfer/blob/v$FREESURFER_VERSION/utils/matrix.cpp#L1391-L1407).
  - `m_data` is `MatrixAlloc`-backed which
    calloc-zeros, so the unwritten row
    contributes a vector of zeros.
