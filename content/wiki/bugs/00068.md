# [severity-1] [bug-00068] `IsSubCorticalGray` and `IS_THALAMUS` — duplicate Thalamus checks

> [!bug] Synopsis
> `IsSubCorticalGray`
> ([`utils/cma.cpp:463-489`](https://github.com/freesurfer/freesurfer/blob/v$FREESURFER_VERSION/utils/cma.cpp#L463-L489))
> tests segment IDs for sub-cortical gray membership.
> Lines
> [`:465-468`](https://github.com/freesurfer/freesurfer/blob/v$FREESURFER_VERSION/utils/cma.cpp#L465-L468)
> read:
>
> ```cpp
> if (SegId == Left_Thalamus) return (1);
> if (SegId == Right_Thalamus) return (1);
> if (SegId == Left_Thalamus) return (1);    /* :467 — duplicate */
> if (SegId == Right_Thalamus) return (1);   /* :468 — duplicate */
> ```
>
> The macro `IS_THALAMUS`
> ([`include/cma.h:529`](https://github.com/freesurfer/freesurfer/blob/v$FREESURFER_VERSION/include/cma.h#L529))
> has the same shape:
>
> ```cpp
> #define IS_THALAMUS(label)  (((label) == Left_Thalamus)  ||
>                              ((label) == Left_Thalamus)  ||  /* duplicate */
>                              ((label) == Right_Thalamus) ||
>                              ((label) == Right_Thalamus))    /* duplicate */
> ```
>
> Functionally redundant: `Left_Thalamus ==
> Left_Thalamus_Proper == 10` and `Right_Thalamus ==
> Right_Thalamus_Proper == 49` are `#define` aliases
> in
> [`include/cma.h:43-44`](https://github.com/freesurfer/freesurfer/blob/v$FREESURFER_VERSION/include/cma.h#L43-L44)
> and
> [`:83-84`](https://github.com/freesurfer/freesurfer/blob/v$FREESURFER_VERSION/include/cma.h#L83-L84).
> Both functions correctly identify thalamus voxels
> regardless. The shape, though, is the canonical
> "the second instance of each was meant to be
> `*_Thalamus_Proper`" copy-paste smell — and a
> developer reading the source could plausibly
> conclude that two distinct labels are being
> checked when only one (per side) actually is.

## Affected Artefacts

- **Functions:** `IsSubCorticalGray` is called from
  several places (`mri_segstats`, `gtm`, etc.) in the
  same file and elsewhere. `IS_THALAMUS` is a macro
  used wherever thalamus membership is tested.
- **Pipeline stage(s):** none directly. The
  redundancy doesn't change behaviour.
- **FreeSurfer version(s):** confirmed in
  `$FREESURFER_VERSION`.

## Detailed Description

The label aliases at
[`include/cma.h:43-44`](https://github.com/freesurfer/freesurfer/blob/v$FREESURFER_VERSION/include/cma.h#L43-L44)
and
[`:83-84`](https://github.com/freesurfer/freesurfer/blob/v$FREESURFER_VERSION/include/cma.h#L83-L84):

```cpp
#define Left_Thalamus_Proper          10
#define Left_Thalamus                 10
...
#define Right_Thalamus_Proper         49
#define Right_Thalamus                49
```

So `Left_Thalamus == Left_Thalamus_Proper`. The
duplicate checks in `IsSubCorticalGray` and
`IS_THALAMUS` test the same numeric value twice;
the second test is dead code under preprocessing.

The most likely original intent: write the macro /
function to be self-documenting by listing both
canonical and alias names. But the duplication of
`Left_Thalamus` (rather than `Left_Thalamus_Proper`)
suggests a typo.

## Root Cause

Copy-paste with a missed substitution. The author
likely wrote four lines, intending two each for
`*_Thalamus` and `*_Thalamus_Proper`, but accidentally
used `*_Thalamus` for all four.

## Impact

- **Functional:** none. The aliases are equal, so
  the function/macro returns the correct answer.
- **Code-quality:** the duplication may mislead a
  future reader into thinking two distinct labels
  are checked. If the aliases are ever
  decoupled (e.g., a future label scheme assigns
  different numbers to `*_Thalamus_Proper` vs
  `*_Thalamus`), the redundancy becomes a real
  defect.

## Recommended Fix

Replace the duplicates with the alias names:

```diff
--- a/utils/cma.cpp
+++ b/utils/cma.cpp
@@ -464,8 +464,8 @@ int IsSubCorticalGray(int SegId)
 {
   if (SegId == Left_Thalamus) return (1);
   if (SegId == Right_Thalamus) return (1);
-  if (SegId == Left_Thalamus) return (1);
-  if (SegId == Right_Thalamus) return (1);
+  if (SegId == Left_Thalamus_Proper) return (1);
+  if (SegId == Right_Thalamus_Proper) return (1);
```

```diff
--- a/include/cma.h
+++ b/include/cma.h
@@ -528,1 +528,1 @@
-#define IS_THALAMUS(label)  (((label) == Left_Thalamus) || ((label) == Left_Thalamus) || ((label) == Right_Thalamus) || ((label) == Right_Thalamus))
+#define IS_THALAMUS(label)  (((label) == Left_Thalamus) || ((label) == Left_Thalamus_Proper) || ((label) == Right_Thalamus) || ((label) == Right_Thalamus_Proper))
```

Self-documenting and future-proof.
