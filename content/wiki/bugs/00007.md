# [severity-5] [bug-00007] SupraTentorialVolCorrection / CorticalGMVolCorrection — thalamus voxels double-counted

> [!bug] Synopsis
> Both `SupraTentorialVolCorrection` and `CorticalGMVolCorrection` in
> `utils/cma.cpp` contain a back-to-back pair of identical tests for
> the thalamus label on the left and right hemispheres. Each thalamus
> voxel that passes the ribbon/region filter therefore adds its voxel
> volume **twice** to the running total. In the supratentorial case
> the inflated total flows into `mri_brainvol_stats`'s `SupraTentVol`
> (and `SupraTentVolNotVent`), which are the standard volume measures
> reported in `stats/aseg.stats` and consumed by group analyses. The
> cortical-GM variant has the same defect but no in-tree caller at
> this commit.

## Affected Artefacts

- **Tool(s):** [[mri_brainvol_stats]] (producer of
  `stats/brainvol.stats`), and the downstream consumers of that
  cache — [[mri_segstats]] and [[mris_anatomical_stats]], which
  propagate the biased values into `stats/aseg.stats` and the
  per-hemisphere `stats/?h.aparc*.stats`.
- **Pipeline stage(s):** `autorecon3` — `mri_brainvol_stats` is
  invoked near the end of [[wiki/pipelines/recon-all|recon-all]] to populate
  `stats/brainvol.stats`.
- **FreeSurfer version(s):** confirmed in `8.2.0` at commit
  `d932c45b79`.
- **Platforms:** all — purely arithmetic.
- **Triggering configuration:** always-on for every [[wiki/pipelines/recon-all|recon-all]]
  invocation that reaches `mri_brainvol_stats`. The cortical-GM
  variant is latent today because `CorticalGMVolCorrection` has no
  in-tree caller at this commit.

## Detailed Description

`SupraTentorialVolCorrection` iterates over all aseg voxels that fall
outside the cortical ribbon and accumulates the voxel volume of
subcortical structures that the pial surface does not enclose. The
list of target labels is encoded as a long sequence of `if (SegId ==
…) vol += VoxSize;` statements. Two of those statements are duplicated
verbatim for the thalamus, so each thalamus voxel contributes
`2 × VoxSize` instead of `1 × VoxSize` to the running total.

The header in [`include/cma.h:43–44`](https://github.com/freesurfer/freesurfer/blob/v8.2.0/include/cma.h#L43-L44) and `:83–84` defines
`Left_Thalamus` and `Left_Thalamus_Proper` as aliases for the same
integer label (`10`), and likewise `Right_Thalamus` /
`Right_Thalamus_Proper` as `49`, so the two duplicated tests resolve
to the same predicate on the underlying label value. This is not a
case of testing two different labels that happen to share a name — it
is a literal duplicate.

### Expected Behaviour

Each voxel's volume should be added to `vol` at most once per
hemispheric label. A thalamus voxel should contribute exactly
`VoxSize` millilitres (one voxel's volume) to the supratentorial or
cortical-GM correction.

### Observed Behaviour

Each qualifying thalamus voxel contributes `2 × VoxSize`. For a
conformed 1 × 1 × 1 mm volume with typical adult thalami (~7.5 cc per
hemisphere, nearly all of which sit outside the cortical ribbon and
therefore pass the `RibbonVal > 0` guard), the inflation is on the
order of **15 cc** in the supratentorial total — a ~1–1.5 %
over-estimate of `SupraTentVol` (typical adult ~1.1 L) and a similar
over-estimate of `SupraTentVolNotVent`. The bias is systematic: the
reported supratentorial volume is always too large, never too small.

```cpp
double SupraTentorialVolCorrection(MRI *aseg, MRI *ribbon)
{
  int c, r, s, SegId;
  double vol = 0;
  int RibbonVal;
  double VoxSize;

  VoxSize = aseg->xsize * aseg->ysize * aseg->zsize;
  for (c = 0; c < aseg->width; c++) {
    for (r = 0; r < aseg->height; r++) {
      for (s = 0; s < aseg->depth; s++) {
        RibbonVal = MRIgetVoxVal(ribbon, c, r, s, 0);
        if (RibbonVal > 0) continue;

        SegId = MRIgetVoxVal(aseg, c, r, s, 0);
        /* ... earlier labels elided ... */
        if (SegId == WM_hypointensities) vol += VoxSize;
        if (SegId == Left_WM_hypointensities) vol += VoxSize;
        if (SegId == Right_WM_hypointensities) vol += VoxSize;
        if (SegId == Left_Thalamus) vol += VoxSize;       // line 538
        if (SegId == Right_Thalamus) vol += VoxSize;      // line 539
        if (SegId == Left_Thalamus) vol += VoxSize;       // line 540 — duplicate
        if (SegId == Right_Thalamus) vol += VoxSize;      // line 541 — duplicate
        if (SegId == CC_Posterior) vol += VoxSize;
        /* ... remaining labels ... */
      }
    }
  }
  return (vol);
}
```

The label aliasing that makes these tests equivalent:

- **File:** `include/cma.h`
- **Lines:** `43–44` and `83–84`
- **Commit:** `d932c45b79`

```cpp
// 9 used to be thalamus and 10 thalamus_proper
#define Left_Thalamus_Proper          10
#define Left_Thalamus                 10
// ...
// 48 used to be thalamus and 49 thalamus_proper
#define Right_Thalamus_Proper         49
#define Right_Thalamus                49
```

Because both names resolve to the same integer, the two `if` tests in
each pair are literally the same predicate.

## Root Cause

Almost certainly a copy-paste artefact. The list of labels in both
functions is hand-maintained; a recent refactor likely intended to
add `Left_Thalamus_Proper` / `Right_Thalamus_Proper` on two of the
lines (matching the `WM_hypointensities` / `Left_WM_hypointensities` /
`Right_WM_hypointensities` triple above), but because the header
defines `_Proper` and the bare form as aliases, the two intended
variants collapsed into literal duplicates of lines 538–539 (and
631–632 in the sister function).

The comments in [`cma.h:42`](https://github.com/freesurfer/freesurfer/blob/v8.2.0/include/cma.h#L42) and [`cma.h:82`](https://github.com/freesurfer/freesurfer/blob/v8.2.0/include/cma.h#L82) — "9 used to be thalamus
and 10 thalamus_proper" — confirm that the bare and `_Proper` names
were separate labels in an earlier FreeSurfer schema and were merged
onto the same integer later. The call sites in `cma.cpp` did not get
the matching update, and the duplicate now simply re-runs the same
test.

## Impact

- **`SupraTentVol` (stats index 2).** Inflated by the sum of thalamus
  voxels outside the cortical ribbon, on both hemispheres, counted
  once in excess. Typical adult inflation ≈ 15 cc, ≈ 1.3 % of the
  true value; the bias is systematic and one-sided (always too
  large).
- **`SupraTentVolNotVent` (stats index 3).** Carries the same bias
  because it is computed as `SupraTentVol − VentChorVol` and the
  ventricle correction is unaffected.
- **Downstream consumers.** `mri_segstats` and
  `mris_anatomical_stats` read `brainvol.stats` and reproduce the
  biased `SupraTentVol` / `SupraTentVolNotVent` in `aseg.stats`,
  `?h.aparc*.stats`, and derived files. Any group analysis that
  normalises by supratentorial volume — including the common
  "eTIV / SupraTentVol" covariate regression — carries the bias
  forward as a small systematic offset.
- **`CorticalGMVolCorrection`.** No in-tree caller at
  `d932c45b79`, so the sister defect is latent today. Worth fixing
  alongside the supratentorial variant since the duplicated lines
  would surface the moment someone wires the function into a volume
  pipeline.

## Recommended Fix

Delete the duplicate lines in both functions:

```diff
   if (SegId == Left_WM_hypointensities) vol += VoxSize;
   if (SegId == Right_WM_hypointensities) vol += VoxSize;
   if (SegId == Left_Thalamus) vol += VoxSize;
   if (SegId == Right_Thalamus) vol += VoxSize;
-  if (SegId == Left_Thalamus) vol += VoxSize;
-  if (SegId == Right_Thalamus) vol += VoxSize;
   if (SegId == CC_Posterior) vol += VoxSize;
```

Apply the same two-line deletion to `CorticalGMVolCorrection`
([`utils/cma.cpp:633–634`](https://github.com/freesurfer/freesurfer/blob/v8.2.0/utils/cma.cpp#L633-L634)).

### Alternative Fixes Considered

If the author's original intent was to include a separate pair of
labels (e.g., `Left_Thalamus_Proper` / `Right_Thalamus_Proper`, or a
distinct subnucleus label introduced later), the fix is to replace
the duplicates with the intended labels rather than delete them. The
`cma.h` aliasing makes this a harder call to settle from the code
alone: at the audited commit, `_Proper` is an exact alias, so no
distinct label currently exists to add here. Until a developer
confirms otherwise, deletion is the safe minimal fix.

## Workarounds (If Any)

Subtract the thalamus voxel counts from `SupraTentVol` and
`SupraTentVolNotVent` by hand. For a conformed 1 mm isotropic
subject:

```bash
# Read thalamus voxel counts from aseg.stats, convert to mm^3,
# subtract from SupraTentVol / SupraTentVolNotVent in brainvol.stats.
```

This only compensates for the supratentorial-side inflation; there is
no user-visible manifestation of the cortical-GM-side duplicate today.

## Confidence and Gaps

> [!gap] Original intent
> It is possible that the duplicated lines were stubs for a
> separate subnucleus label (e.g., a prospective
> `Left_Thalamus_Other` or a CC-adjacent thalamic region) that was
> never introduced, leaving the placeholders collapsed. A FreeSurfer
> maintainer who owns `mri_brainvol_stats` should confirm before
> merging the one-line deletion.

> [!gap] Magnitude of downstream effect
> The ~15 cc estimate above assumes a 1 mm isotropic conformed volume
> and typical adult thalami. For clinical or paediatric data the
> absolute value shifts, but the relative inflation (thalamic mass
> ÷ supratentorial mass) is close to 1–2 %.
