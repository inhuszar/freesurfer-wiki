# [severity-3] [bug-00150] `FCDcomputeThicknessLabels` parcel-boundary guard is broken — `base_label` never updates, `break` never fires, thickness diffs accumulate across every parcel the cortical normal traverses

> [!bug] Synopsis
> ```cpp
> /* utils/fcd.cpp:434-468 (LH branch; the RH twin at :501-540 is identical) */
> for (d = 0, base_label = 0; d < thickness; d += 0.25) {
>   double xv, yv, zv;
>   double xs = v->x + d * v->nx;
>   double ys = v->y + d * v->ny;
>   double zs = v->z + d * v->nz;
>   MRISsurfaceRASToVoxel(fcd->mris_lh, fcd->mri_thickness_increase, xs, ys, zs, &xv, &yv, &zv);
>   int xvi = nint(xv);
>   int yvi = nint(yv);
>   int zvi = nint(zv);
>   int label = MRIgetVoxVal(fcd->mri_aparc, xvi, yvi, zvi, 0);
>   if (IS_WM(label) == 0 && label >= MIN_CORTICAL_PARCELLATION && label != ctx_lh_unknown) {
>     if (label != base_label) {
>       if (base_label) {
>         break;                         /* :447 — fires only if base_label != 0 */
>       }
>     }
>     else {
>       base_label = label;              /* :451 — fires only if label == base_label */
>     }
>     if (val >= 0) { ... }              /* accumulate thickness_increase */
>     else          { ... }              /* accumulate thickness_decrease */
>   }
> }
> ```
>
> Trace with `base_label = 0` (initial) and any non-zero `label` that passes the filter:
>
> | Iteration | `label` | `label != base_label` | `base_label` branch entered | `base_label` after |
> |---|---|---|---|---|
> | 1 | `1001` (non-zero parcel) | `1001 != 0` → TRUE | outer-if; `if (0)` → no break | still `0` |
> | 2 | `1001` | `1001 != 0` → TRUE | same as iter 1 | still `0` |
> | 3 | `2002` (different parcel) | `2002 != 0` → TRUE | same as iter 1 | still `0` |
> | … | … | always TRUE | break never fires | still `0` |
>
> The `else` branch at `:450-452` (which sets `base_label = label`) is bound to the **outer** `if (label != base_label)` and only fires when `label == base_label`. While `base_label == 0` and `label` is any non-zero parcel that passed the filter, `label != base_label` is always TRUE → the outer-if path is taken → `base_label` never updates → the `if (base_label) break;` at `:447` is always false → the break never fires.
>
> Intended logic: track the parcel of the *first* qualifying voxel along the normal; break when the normal crosses into a *different* parcel. Correct form:
>
> ```cpp
> if (base_label == 0) {
>   base_label = label;                  /* first time set */
> }
> else if (label != base_label) {
>   break;                                /* hit a new parcel */
> }
> ```
>
> Or, with the original nesting style and a single fix:
>
> ```cpp
> if (label != base_label) {
>   if (base_label) {
>     break;
>   } else {
>     base_label = label;                 /* set on first hit */
>   }
> }
> ```
>
> The bug-fix needed is moving the `base_label = label;` line **inside** the `if (label != base_label)` block (specifically, as the `else` of the inner `if (base_label)`), not outside as the alternative branch of the outer `if`.

## Detailed Description

`FCDcomputeThicknessLabels` is the core routine for asymmetry-based FCD detection. For each vertex `v` on the white surface, it walks outward along the surface normal in 0.25-mm steps up to the cortical thickness at `v`, mapping each sample point to the underlying parcellated aparc volume. At each sample point inside cortex (non-WM, non-unknown, parcel-id ≥ `MIN_CORTICAL_PARCELLATION`), it accumulates the LH-RH thickness asymmetry value `val` into the running `mri_thickness_increase` / `mri_thickness_decrease` maps at that voxel.

The accumulation is intended to stop as soon as the normal walk leaves the *original* aparc parcel of vertex `v`. The reason is anatomical: an FCD is a focal lesion within a single cortical parcel, and accumulating asymmetry values across parcels would dilute the focal signal with values from anatomically distinct regions (e.g., precentral vs postcentral gyrus).

### Expected Behaviour

- First qualifying voxel along the normal: record its parcel id in `base_label`.
- Subsequent same-parcel voxels: continue accumulating.
- First voxel in a *different* parcel: `break` and stop.

### Observed Behaviour

The if/else nesting is swapped:

- `base_label` starts at `0`.
- On every iteration, `label != base_label` is true (label is a non-zero parcel; base_label is 0) → outer if entered → inner `if (base_label)` is false → no break.
- The `else` (which would set `base_label`) is the `else` of the **outer** if and only fires when `label == base_label`. That equality holds only after `base_label` is already set — but it never gets set, so the else never fires.

Net effect: `base_label` stays at 0 forever, the break never fires, and the loop continues for the full `thickness` distance regardless of how many parcels the normal traverses. The asymmetry values from ALL cortical voxels along the normal — possibly in multiple anatomically distinct parcels — get accumulated into `mri_thickness_increase` / `mri_thickness_decrease`.

For thin cortices the impact is small (the normal usually stays in one parcel for 2–4 mm). For voxels near parcel boundaries, the impact grows: the accumulated asymmetry is a mixture of the vertex's own parcel and at least one neighbor. For voxels near triple-parcel junctions, the mixture spans three or more parcels.

## Root Cause

A nesting / brace-placement slip. The author wrote a 2-level decision tree:

> "If we're now in a different parcel than the recorded one, break (but only after the first one has been recorded). Otherwise (same parcel), set / confirm the recorded one."

…but transcribed it as:

```cpp
if (label != base_label) {     /* different from recorded */
  if (base_label) { break; }   /* break if recorded was non-zero */
}
else {                          /* same as recorded */
  base_label = label;           /* set the recorded value */
}
```

The `else { base_label = label; }` was placed at the wrong level of the if/else cascade. Logically, the recording should happen on the *first* hit (when `base_label == 0`), not on subsequent same-parcel hits. The correct nesting puts the `base_label = label;` as the `else` of the inner `if (base_label)`, not as the alternative to the outer `if (label != base_label)`.

The defect is silent at compile time (well-formed C++), latent in test (the loop still executes; downstream `mri_thickness_increase` / `mri_thickness_decrease` are still populated), and only detectable by either an A/B comparison against a fixed implementation or by tracing the loop variable values by hand.

## Impact

- **FCD detection's parcel-boundary guard is non-functional on every invocation.** Both LH and RH have the same defect.
- **Asymmetry maps are diluted with cross-parcel values.** The deeper a cortical normal walks and the closer the source vertex is to a parcel boundary, the more dilution occurs.
- **Quantitative effect is anatomy-dependent.** For interior-of-parcel vertices, the normal usually stays in one parcel; the bug has little effect. For boundary vertices, the normal exits the original parcel within 1–2 mm; the bug propagates asymmetry values across the boundary.
- **Downstream FCD-candidate detection** (label segmentation, cluster size filtering, sorting by `avg_stat`) inherits the diluted asymmetry signal. False positives concentrate at parcel boundaries; the most-focal FCDs (centered well inside a single parcel) are still detected, but boundary-straddling ones may be miscentred.
- **No `recon-all` impact.** FCD detection is an opt-in workflow; FCDcomputeThicknessLabels is not on the default recon-all path.

## Recommended Fix

Single-block edit in both LH and RH branches: move `base_label = label;` from the outer `else` to a new `else` inside the outer `if`.

```diff
   if (IS_WM(label) == 0 && label >= MIN_CORTICAL_PARCELLATION && label != ctx_lh_unknown) {
     if (label != base_label) {
       if (base_label) {
         break;
+      } else {
+        base_label = label;
       }
     }
-    else {
-      base_label = label;
-    }
     if (val >= 0) { ... }
     else          { ... }
   }
```

The same diff applies to the RH branch at `:511-519`.

### Alternative

Restructure as the cleaner `if (base_label == 0) { base_label = label; } else if (label != base_label) { break; }`. Functionally identical to the diff above; preference is stylistic.

## Workarounds (If Any)

- **Restrict FCD candidates to vertices well inside a single aparc parcel** (e.g., filter out vertices whose nearest parcel-boundary is < 3 mm away).
- **Visually verify FCD candidates** against the underlying aparc parcellation; reject candidates that straddle two parcels.
