# [severity-2] [bug-00076] `MRIaverageFrames` ignores caller-supplied `mri_dst`

> [!bug] Synopsis
> `MRIaverageFrames`
> ([`utils/mri.cpp:16793-16813`](https://github.com/freesurfer/freesurfer/blob/v$FREESURFER_VERSION/utils/mri.cpp#L16793-L16813))
> takes a `mri_dst` parameter but unconditionally
> allocates a new MRI at
> [`:16801`](https://github.com/freesurfer/freesurfer/blob/v$FREESURFER_VERSION/utils/mri.cpp#L16801):
>
> ```cpp
> mri_dst = MRIalloc(mri_src->width, mri_src->height, mri_src->depth, MRI_FLOAT);
> ```
>
> The caller's `mri_dst` is overwritten by the local
> assignment and silently leaked. The function
> returns the new allocation, so the caller's code
> continues to work — but the buffer they passed in
> is orphaned. The sister function `MRIaddToFrame`
> immediately following at
> [`:16815-16820`](https://github.com/freesurfer/freesurfer/blob/v$FREESURFER_VERSION/utils/mri.cpp#L16815-L16820)
> correctly tests `if (mri_dst == NULL) mri_dst =
> MRIcopy(mri_src, NULL);`.

## Affected Artefacts

- **Function:** `MRIaverageFrames`. Searches show
  no in-tree caller passes a non-NULL `mri_dst`, so
  the leak is currently latent.
- **Pipeline stage(s):** none.
- **FreeSurfer version(s):** confirmed in
  `$FREESURFER_VERSION`.

## Detailed Description

```cpp
MRI *MRIaverageFrames(MRI *mri_src, MRI *mri_dst, int start_frame, int end_frame)
{
  ...
  mri_dst = MRIalloc(mri_src->width, mri_src->height, mri_src->depth, MRI_FLOAT);   /* (!) */
  MRIcopyHeader(mri_src, mri_dst);
  ...
  return (mri_dst);
}
```

The function header says "averageFrames(... MRI
*mri_dst ...)" implying the caller may pass either
NULL or a pre-allocated destination. The body
ignores the caller's input.

Compare the immediately-following sister:

```cpp
MRI *MRIaddToFrame(MRI *mri_src, MRI *mri_to_add, MRI *mri_dst, int src_frame_no, int dst_frame_no)
{
  ...
  if (mri_dst == NULL) mri_dst = MRIcopy(mri_src, NULL);
  ...
}
```

## Code Reference

- **File:** [`utils/mri.cpp`](https://github.com/freesurfer/freesurfer/blob/v$FREESURFER_VERSION/utils/mri.cpp)
- **Function:** `MRIaverageFrames`
- **Defect:**
  [`:16801`](https://github.com/freesurfer/freesurfer/blob/v$FREESURFER_VERSION/utils/mri.cpp#L16801)
- **Sister with correct pattern:**
  [`:16820`](https://github.com/freesurfer/freesurfer/blob/v$FREESURFER_VERSION/utils/mri.cpp#L16820)
  (`MRIaddToFrame`)
- **Commit:** `d932c45b79`

## Root Cause

Missing `if (mri_dst == NULL)` guard. The author
took an `MRI *mri_dst` parameter but didn't write
the standard "use it if non-NULL, allocate
otherwise" pattern.

## Impact

- **Currently latent.** No in-tree caller exercises
  the non-NULL `mri_dst` path.
- **External callers** passing a non-NULL `mri_dst`
  see the buffer they passed get silently leaked
  and replaced with a fresh allocation.
- **Severity:** low.

## Recommended Fix

```diff
--- a/utils/mri.cpp
+++ b/utils/mri.cpp
@@ -16798,7 +16798,10 @@ MRI *MRIaverageFrames(MRI *mri_src, MRI *mri_dst, int start_frame, int end_frame
   if (start_frame < 0) start_frame = 0;
   if (end_frame < 0 || end_frame >= mri_src->nframes) end_frame = mri_src->nframes - 1;

-  mri_dst = MRIalloc(mri_src->width, mri_src->height, mri_src->depth, MRI_FLOAT);
-  MRIcopyHeader(mri_src, mri_dst);
+  if (mri_dst == NULL) {
+    mri_dst = MRIalloc(mri_src->width, mri_src->height, mri_src->depth, MRI_FLOAT);
+    MRIcopyHeader(mri_src, mri_dst);
+  }
   nframes = end_frame - start_frame + 1;
```

## Workarounds

Always pass `NULL` as `mri_dst`.
