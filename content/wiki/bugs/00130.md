## Detailed Description

### What a normalized Gaussian smooth should do

A true Gaussian smooth
preserves the local
mean — i.e., if the
input is constant, the
output equals that
constant. Mathematically:

```
Targ(v) = ∫ G(|v - v'|) · val(v') dA(v')
       ÷ ∫ G(|v - v'|) dA(v')
```

The discrete
approximation on a
mesh requires each
term to be weighted
by the vertex's area
(`vertex->area` in
FreeSurfer):

```
Targ(v) = Σₙ G(d_n) · val(n) · area(n)
        ÷ Σₙ G(d_n)         · area(n)
```

### What the code does

```c
Targ(v) = Σₙ g(d_n) · val(n)
```

where `g(d) = (1/(2πσ²))
exp(-d²/2σ²)` is the 2D
Gaussian PDF (continuous-
domain normalization).

- No `area(n)` factor
  per term.
- No division by the
  sum of weights.

### Magnitude bias

For a uniformly-meshed
sphere with `N`
vertices on a sphere
of radius `R`, average
area per vertex `A = 4πR²/N`.

For a Gaussian with
small enough σ that the
kernel is approximately
flat on the sphere
(σ ≪ R), the sum

```
Σₙ g(d_n) ≈ (1/A) · ∫ g(d) dA = 1/A
```

Therefore

```
Targ(v) ≈ (1/A) · ∫ g · val dA = (1/A) · normalized_smoothed_val
```

So the output is the
correctly-smoothed
value scaled by `1/A`.

For canonical icosahedral
sphere surfaces (radius
100 mm):

| order | vertices | area/vtx (mm²) | amplification (1/A) |
|-------|---------|---------------|---------------------|
| ic5   | 10,242  | ~12.3         | ~0.08×              |
| ic6   | 40,962  | ~3.07         | ~0.33×              |
| ic7   | 163,842 | ~0.77         | ~1.3×               |

So the same input
smoothed onto different
icosahedral meshes
produces dramatically
different output
magnitudes. A constant
input does not yield a
constant output of the
same magnitude.

### Sister `MRISgaussianSmooth2`
in `mris_niters2fwhm.cpp`

[`mris_niters2fwhm/mris_niters2fwhm.cpp:317-510`](https://github.com/freesurfer/freesurfer/blob/v$FREESURFER_VERSION/mris_niters2fwhm/mris_niters2fwhm.cpp#L317-L510)

So this sister

But the structure

**intended** the
area-weighted
normalized form
and disabled it
during development —
both functions are
in the same state.

## Root Cause

Two related lines of
code are disabled:
1. The area weighting
   `ga = g *
   vertex.area` at
   `:3935` is
   commented out.
2. The post-loop
   normalization at
   `:3955` is wrapped
   in `if (0)`.

Either one alone
would make the
smooth wrong; both
together make the
output un-normalized
PDF convolution
without
vertex-density
correction.

The author likely
disabled both during
development /
benchmarking and
the disabled state
got committed.

- **`mri_surf2surf`

- **Default

## Workarounds

For users running
`mri_surf2surf` with
Gaussian smoothing:
use the default
nearest-neighbor
iterative smoothing
path (without
`--cortex-conv`).
This uses
`MRISsmoothMRI`

If Gaussian
smoothing is
required (e.g., for

by the empirically-

target surface,
OR run a smoothing
on a constant-1
input to derive
the per-vertex
density factor and
divide by that.
